# User Interface

## Previous document

The previous team's high-level design document states that the UI will be optimized for mobile use, but accessable on all devices. It lists the following 13 components with details for each one: 
1. Log In/Sign Up
2. Profile Viewing/Editing
3. AI Chat
4. AI Listen-in
5. Cupid Main Page
6. Dater Main Page
7. Manager Main Page
8. Calendar
9. Cupid Cash
10. Manager Report System
11. Feedback System
12. Cupid Gig Finder
13. Cupid Chosen Gig

A UML diagram shows how the components work together generally, and more UML diagrams show how the components work for each type of user with descriptions. An explanation is given for the purpose of the modular design used. After that is a series of photos that show what the different components of the user interface may look like in the app. Lastly, UML diagrams are provided to show how the different users will interact with each other.
